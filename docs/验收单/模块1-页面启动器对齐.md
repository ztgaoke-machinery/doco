## 游戏里的体现
1. **双击 `game.html` 与双击 `多克多比.exe` 看同一份存档**：`file://` 下浏览器读不到 exe 的 `save.json`，现在回落到 `save-web.js` 注入的副本，主菜单三个槽显示的是同一份进度（消费方是模块 2 的 `peekFile()`，两边合起来才成链路）。
2. **第一次进游戏弹取名大框**：标题 + 输入框 + 贴图确认钮；**中文可走输入法**（沿用基线的 DOM `input` 方案，不在 canvas 上抓键盘）；长度上限 10 字。取完名立刻关窗也不会重弹（`flushNow` 绕 400 ms 防抖）。
3. **聊天 / 改名仍是旧的裸输入观感**：同一套 DOM 走 `compact` 模式，不弹大框。
4. **窗口两侧的黑边变成游戏壁纸**，上面压一层极轻暗罩，顶栏文字对比度不掉。
5. **工具栏多一个「高清 开」按钮**（接线在模块 4）。

## 与成品的有意差异（2 处）
1. **`?v=` 版本串只加在 JS 运行时拼的图片 URL 上**，`game.html` 与 `game/style.css` 里的静态引用**不带**
   （成品那两处写着 `save-web.js?v=20261009w-round108`、`bg_page.png?v=20261009w-round108`）。
   原因：CSS 的 `url()` 与 `<script src>` 走不了 `G.assetUrl()`。
   后果：**换 `bg_page.png` 或 `name_ok.png` 后浏览器可能仍给旧图**，需要手动改 CSS 里的 URL 或在文件名上加版本。
   要不要把版本串也写进这两处静态引用（改一次生成一次），请制作人定。
2. **`ASSET_VER` 串不同**：源码侧 `'20261011a-src-round72'`，成品侧 `'20261009w-round108'` ——
   两条线各自的事实源，**不该相等**，但同一张图在两边缓存键不同，交叉对比时别误判成"图不一样"。
