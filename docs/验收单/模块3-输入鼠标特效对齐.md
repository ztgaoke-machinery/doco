# 验收单 · 模块 3：输入 / 鼠标 / 特效对齐

## 改了哪些文件
| 文件 | 改动 |
|---|---|
| `game/engine/mouse.js` | `M.applyCursor(cvs, hovering, icon)` 加第三参 `icon`：直接传一段 CSS cursor 值（例：`url("assets/ui/cursor-wand.png") 6 4, pointer`），战斗页"单体技能瞄准＝魔法棒 / 道具瞄准＝药瓶"要用它 |
| `game/engine/fx.js` | `FX.SKILL_FX` 补 6 个 7k7k 技能的专属特效：魔气弹(dark/ball)、魔焰灼烧(flame/ball)、血冰箭(frost/spear)、魔羽箭(wind/spear)、吸血蔓藤(poison/ball)、血晶地刺(earth/spear) |
| `assets/ui/glyphs*`（图集） | 重生成：字符 2461 → **2462**（新增「灼」，来自技能名"魔焰灼烧"） |

`game/engine/mouse.js` 其余部分（`toCanvas` 读 `__DKDbb_VIEW__`）在模块 4 已一并改好，本模块与成品的差异只剩注释里的文件路径写法（源码写 `core/canvas.js`，成品写 `game.js`）。

## 游戏里的体现
- **特效**：技能表里这 6 个技能（模块 6 会正式进表）出手时不再是"按属性兜底"的通用光球 —— 魔气弹是暗紫弹丸、血冰箭是粉白冰锥、吸血蔓藤是毒绿藤球，颜色各自独立。
- **鼠标**：本模块只是把接口准备好；等你在模块 8 接上战斗瞄准后，鼠标悬到可施法目标上会变成魔法棒/药瓶图标，而不是普通手型。
- **字形**：图集重生成后，"灼"这类以前画不出来的字在画布上能正常显示（以前会被静默跳过）。

## 测试结果
- 先红后绿：新注释引入的「灼」不在图集里 → `test-glyphs` 报缺 1 字 → 跑三步重生成（`gen-glyphs-prep.mjs` → `_gen.ps1` → `gen-glyphs-post.mjs`）后转绿。
